# 调研笔记

## 玩法与叙事来源

本作是原创黄牛生存射击游戏，不关联、不引用任何具体影视作品。玩法原型来自常见生存叙事：弱小的主角必须离开庇护所，穿过危险荒野，抵达会合点，途中面对群居掠食者和伏击型威胁。

## 本作设定

- 玩家：直立行走的黄牛，可持枪射击，也可用牛角近战。
- 敌人：群狼负责持续追击与包围压力；单条蛇负责一击致命的伏击威胁。
- 目标：从随机出生点抵达随机集结点，两者直线距离固定，保证公平。
- 地貌：森林、河流、岩石、小山共同构成可绕行、可遮挡、可涉水的战斗空间。

## Web 3D 技术选型

- **Three.js 0.185.1**：当前稳定主线版本，提供 ES Module 构建、PCF 阴影、ACES 色调映射。
- **原生 ES Modules + 本地 vendor**：无需打包器，适合 GitHub Pages 静态部署。
- **Pointer Lock API**：PC FPS 鼠标视角的标准方案。
- **Pointer Events / 虚拟摇杆**：移动端双摇杆 + 触控按钮，参考手机 FPS 交互。
- **Fullscreen API**：满足手机浏览器非全屏时进入全屏的要求。
- **Web Audio API**：无需外部音频资源即可合成枪声、受伤、换弹等音效。
- **PWA / Service Worker**：提供离线缓存与安装体验。

## 弹道模型

采用“基准散布 + 移动惩罚 + 空中惩罚 + 后坐力热值”的锥形散布模型：

```text
spread = baseSpread
       + recoilHeat
       + (moving ? movingSpread : 0)
       + (airborne ? airborneSpread : 0)
```

后坐力热值随连续射击增加，停止射击后按速率恢复；移动和跳跃会显著提高瞬时散布，符合“站定更准”的原则。
