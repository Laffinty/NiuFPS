# 游戏设计文档

## 1. 世界观

故事取材于电影原创动画的核心意象：孱弱的小牛黄牛必须“站起来”，穿过充满危险的森林/草原，与狼群和灵蛇（小绳头）周旋，最终抵达会合点。游戏将这一过程重写为一场紧张的第一/第三人称生存射击。

本作完全原创，所有 3D 模型和声音均在浏览器端实时生成，不使用任何外部影视素材。

## 2. 核心循环

1. 玩家随机出生在森林一侧，集结点随机生成在另一侧。
2. 玩家沿森林前进，途中与狼群和一条蛇战斗或绕行。
3. 抵达集结点判定胜利；血量归零判定失败。
4. 每局地图、怪物分布、出生点/集结点重新随机。

## 3. 公平性设计

出生点和集结点使用以下算法：

- 固定直线距离 `SPAWN.distance`（默认 305 米）。
- 先随机方向角，再在保证两个端点都落在世界边界内的“可行中点区域”中随机取中点。
- 两点分别为 `mid - dir * d` 与 `mid + dir * d`，因此直线距离恒为 `2d`。
- 过滤河流、障碍物和边界，避免不可到达或出生即卡住。

这样每一局的难度主要取决于地形与怪物分布，而非出生点之间的距离差异。

## 4. 场景

- **森林**：约 430 × 430 米，低多边形地面 + 顶点色草地。
- **河流**：沿 X 轴穿过中央，河道下沉，玩家可涉水但移动变慢。
- **岩石**：随机分布，参与碰撞与子弹阻挡。
- **小山**：多层分形噪声抬升地形，高处岩石质感。
- **树木**：随机分布，树干参与碰撞，树冠参与阴影和视线遮挡。

## 5. 玩家

模型为直立行走的黄色公牛，具备牛角、双耳、四肢和拟人手臂。

### 5.1 AK-47 模式

- 按 `1` 切换。
- 键位参考 CS1.5：WASD 移动、鼠标瞄准、左键射击、R 换弹、Ctrl 蹲、Shift 静步、Space 跳。
- 弹道参考 VALORANT：
  - 站立静止：基础散布很小，首发最准。
  - 移动：散布显著扩大。
  - 跳跃/空中：散布最大。
  - 连续射击：后坐力热值累积，准星扩大，停止射击后逐步恢复。
  - 命中判定使用射线与命中球体，支持头部暴击。
- 弹匣 30 发，备弹 120 发，换弹时间 2.2 秒。

### 5.2 头槌模式

- 按 `2` 切换。
- 左键/开火键释放前冲头槌，用牛角对前方扇形范围内的怪物造成伤害并击退。
- 冷却 0.82 秒。

## 6. 怪物

### 狼

- 默认 100 只，按难度倍率调整。
- 状态机：`游荡 roam` → `追击 chase` → `攻击 attack`。
- 游荡时随机选择路点；玩家进入仇恨半径后追击；贴近后按攻击冷却造成伤害。
- 同类间有简单排斥，避免大量重叠。

### 蛇

- 仅 1 条，绿色灵蛇形象致敬“小绳头”。
- 游荡/追击/咬击三态。
- 咬中必死（伤害值设为 9999）。
- 由头部和 9 段身体组成，命中判定为多个球体。

### 血量条

- 玩家血量显示在 HUD。
- 怪物受伤后头顶显示 Sprite 血量条，仅在被攻击后出现。

## 7. 视角

### 第一人称

- 参照 CS1.5，相机位于牛眼高度，画面右下可见牛手与 AK-47。
- 鼠标通过 Pointer Lock 控制。

### 第三人称

- 相机位于玩家后方，目标点在牛胸口。
- 适合观察模型和周围环境。

按 `V` 或手机“视角”按钮切换。

## 8. 移动端适配

- 自动检测 `pointer: coarse` / 多点触控。
- 左半屏：虚拟摇杆控制移动。
- 右半屏：拖动控制视角，模仿吃鸡 FPS。
- 右侧按钮：开火、跳跃、蹲下、换弹、切枪、视角。
- 非全屏时弹出全屏提示按钮。

## 9. 技术架构

- **渲染**：Three.js 0.185.1，WebGLRenderer + PCFSoft 阴影。
- **模块化**：原生 ES Modules，无打包器。
- **依赖**：`three.module.js` 与 `three.core.js` 本地 vendor，避免运行时 CDN。
- **PWA**：`manifest.webmanifest` + Service Worker 离线缓存。
- **音效**：Web Audio API 实时合成。
- **辅助**：Python 用于静态校验和本地静态服务器。

## 10. 性能策略

- 世界 144 段高度场，约 2 万顶点。
- 低多边形模型，单个怪物约 12–20 个网格。
- 阴影贴图 2048，像素比上限 2。
- 粒子与拖尾使用短生命周期并复用几何体。
- 死亡怪物立即从主循环移除。

## 11. 参数配置

所有关键参数集中在 `web/src/config.js`，包括世界尺寸、出生距离、武器数值、AI 范围、难度倍率。
