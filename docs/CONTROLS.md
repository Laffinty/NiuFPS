# 操作说明

## PC 键鼠

| 按键 | 功能 |
| --- | --- |
| W / A / S / D | 前 / 左 / 后 / 右移动 |
| 鼠标 | 视角 |
| 鼠标左键 | 射击 / 头槌 |
| 1 | 切换 AK-47 |
| 2 | 切换牛角头槌 |
| R | 换弹 |
| V | 第一/第三人称切换 |
| Space | 跳跃 |
| Ctrl（或 C） | 蹲下 |
| Shift | 静步，降低散布与噪音 |
| Esc | 暂停 / 释放鼠标 |

进入游戏后点击画面即可锁定鼠标；按 Esc 暂停并释放鼠标。

## 手机触控

| 控件 | 功能 |
| --- | --- |
| 左下虚拟摇杆 | 移动 |
| 右半屏拖动 | 视角 |
| 开火 | AK 射击 / 头槌 |
| 跳跃 | 跳跃 |
| 蹲下 | 蹲下 |
| 换弹 | 为 AK-47 换弹 |
| 切枪 | 在 AK-47 与头槌间切换 |
| 视角 | 第一/第三人称切换 |

手机浏览器未进入全屏时，屏幕底部会显示全屏按钮，点击即可全屏。

## 战斗提示

- 站立不动时射击最准，边跑边打散布很大。
- 连续射击会扩大准星，短点射更稳定。
- 狼群数量大，优先走位和利用树木/岩石。
- 蛇咬中即死，务必保持距离或用 AK 提前清理。
- 头槌近距离伤害高，并能击退怪物，适合被包围时突围。
